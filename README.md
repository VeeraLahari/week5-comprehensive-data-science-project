# Week 5 - Comprehensive Data Science Project

## Project Overview
This final-week project integrates the major data science skills developed during the internship: data acquisition and cleaning, exploratory data analysis, visualization, statistical analysis, hypothesis testing, machine learning, model evaluation, and strategic recommendations.

## Key Areas
- Data preprocessing and exploratory analysis
- Data visualization
- Statistical hypothesis testing
- Logistic Regression classification
- Accuracy, precision, recall, F1-score and ROC-AUC
- Confusion matrix and ROC curve
- Error analysis
- Strategic recommendations
- Business/research impact
- Limitations and future improvements

## Dataset
The machine learning section uses the Breast Cancer Wisconsin Diagnostic Dataset available through Scikit-learn.

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy and Scikit-learn.

## Main Files
- `week5_comprehensive_data_science_project.py` - combined analysis and machine learning code
- `Week5_Comprehensive_Data_Science_Project_Report.docx` - final report
- `requirements.txt` - Python dependencies
- `week5_visualizations/` - supporting charts
